We found our own evaluation bug and corrected the numbers.

The merged datasets ingest the same photos through different sources. Perceptual hashing found duplicates across train and test splits; 2,406 leaked test images were quarantined. Accuracy moved from an inflated 94.30% to an honest 91.77%.

Known limits, shown instead of hidden.

Domain shift Partly fixed, partly open

Fixed: the classifier was fine-tuned on the detector's own crops, lifting production-distribution accuracy from 76.9% to 88.9%. Open: on fully unseen capture sessions the detector drops to 0.474 mAP50; closing that needs new training data sources, not more training.

Tiny objects Resolution tested and ruled out

A 960px training run was evaluated: validation unchanged, unseen-batch recall up 3.9 points. Small objects remain the main source of misses, but the binding constraint is training-data diversity, not input resolution.

Waste-state decision Rule logic, not a trained head

The waste / not-waste / review decision is conservative rule logic until a dedicated state model is trained on labeled state data.
